# รถแห่ LIVE

เว็บสำหรับแสดงตัวละครผู้ชม TikTok LIVE บนฟลอร์รถแห่ พร้อมหน้าสำหรับนำไปใช้เป็น Browser Source ในโปรแกรมไลฟ์

ผู้ชมที่ระบบได้รับเหตุการณ์เข้าร่วมหรือกิจกรรมจะปรากฏบนฟลอร์เป็นเวลา 1 นาที ทุก 10 ใจที่ระบบได้รับจากผู้ชมนั้นจะเพิ่มเวลา 1 นาที และเมื่อหมดเวลาแล้ว ผู้ชมสามารถกดใจครบ 10 ใจเพื่อกลับมาได้ รายชื่อและเวลาจะอยู่ในหน่วยความจำของเซิร์ฟเวอร์และเริ่มใหม่เมื่อเชื่อมต่อไลฟ์อีกครั้งหรือปิดเซิร์ฟเวอร์

## เริ่มใช้งาน

1. ติดตั้ง Node.js รุ่น LTS พร้อม npm จาก https://nodejs.org/
2. เปิดเทอร์มินัลในโฟลเดอร์โปรเจกต์ แล้วรัน `npm install` และ `npm start`
3. เปิด http://localhost:3000 เปิด TikTok LIVE แล้วกรอกชื่อบัญชีที่กำลังไลฟ์ หรือใช้โหมดทดสอบเพื่อเพิ่มผู้ชมจำลอง
4. ในโปรแกรมไลฟ์ เพิ่ม Browser Source ด้วย URL http://localhost:3000/overlay และปรับขนาดแหล่งภาพให้เต็มฉาก

บน Windows สามารถดับเบิลคลิก `Start-RotHae.cmd` ในโฟลเดอร์โปรเจกต์ได้ เปิดหน้าต่างที่รันเซิร์ฟเวอร์ค้างไว้ระหว่างใช้งาน

## ข้อจำกัด

ใช้ไลบรารีชุมชน [tiktok-live-connector](https://github.com/zerodytrash/TikTok-Live-Connector) ซึ่งไม่ใช่ API อย่างเป็นทางการของ TikTok การเชื่อมต่ออาจต้องใช้บริการเซ็นคำขอหรือการตั้งค่าเพิ่มเติมและอาจเปลี่ยนแปลงได้ TikTok อาจไม่ส่งทุกเหตุการณ์เข้าร่วมและกดใจ ดังนั้นจำนวนผู้ชมและยอดใจที่ระบบได้รับอาจไม่ครบถ้วน ดูรายละเอียดที่ [เอกสารตัวเชื่อมต่อ](https://ttlc.docs.isaackogan.com/)
